# Choosing Features

[All resources](../README.md)

## Learning the features

- [Onshape Learning Center](https://learn.onshape.com/): free courses, including sketching and part design
- [Onshape Help](https://cad.onshape.com/help): reference for every feature

## Beyond traditional CAD

- [Blender](https://www.blender.org/): mesh modeling for organic shapes and art
- [FreeCAD](https://www.freecad.org/): free, open-source parametric CAD
- [CadQuery](https://cadquery.readthedocs.io/): build parts from Python
- [build123d](https://build123d.readthedocs.io/): another Python CAD library
